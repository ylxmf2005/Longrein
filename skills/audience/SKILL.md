# audience

受众不是一组人口标签，而是一个人在具体处境中，带着已有理解，经由某种媒介继续理解、判断或行动的关系。让产物从这段关系长出来，不从 Prompt、制作过程或现成模板反推受众需要。

把本 Skill 当作具体创作 Skill 的辅助判断层。它调节产物面向人的语义、内容、结构与呈现，不生产固定产物，也不接管工作流阶段。

## 先让真实使用关系显形

从真实对象和使用现场理解：谁会在什么情境下接触这个产物，他需要因此继续理解、比较、决定、执行、维护或排障什么，他已经知道什么、哪些关系不能假定他知道，以及产物最终在哪种媒介中成立。这些是帮助判断的关系，不是创作前必须逐项填满的表单。

让真实责任决定主线和轻重。多数产物需要一条清晰主线；确有多个受众或任务时，用层级、分区或不同路径承载它们，不强行压成一个平均受众，也不让辅助任务争抢同一层级。

能从真实对象、既有受众和使用现场查明的事实自行调查。只有不同答案会实质改变内容责任、结构、披露边界或用户承诺，且现有证据无法判断时才询问用户；其余选择作出连贯判断，并在成品外如实说明必要假设。

## 管理产物塑造的理解

产物不只传递显式信息，也会改变受众更容易注意、联想和推断什么。术语、例子、类比、语气、结构、视觉强调和省略都参与塑造理解；判断一个元素时，既看它直接说了什么，也看它激活、放大或遮蔽了什么。

高密度概念、领域语言和成熟范式可以用很短的表达建立整体语义方向。不要因为它们不能改写成一条立即可执行的说明就删除；先判断它们在催化哪种理解或判断，以及连带语义是否适合当前受众。受众必须据此行动的事实、承诺、风险和披露边界应当显式，整体关系、风格与专业判断不必被压平成属性清单。

示例、参考、类比和模板不是中性说明，而是有方向的校准输入。使用前明确希望它校准什么；使用后区分值得继承的关系与偶然表面，避免单一案例在可能性尚未展开时把创作悄悄改成模仿。

## 让成品只承担成品责任

每个进入成品的元素都应帮助目标受众理解对象、辨别关系、建立必要的语义方向、作出决定、完成动作或处理真实状态。无法指出任何责任的标题、说明、标记、装饰和细节，优先删除，而不是换一种说法保留。

把产物脱离 Prompt、diff、MR、聊天记录和制作过程单独交给目标受众：它仍应准确、够用，不会让人误解，并能把受众带向正确的下一步。这是成品的快照检查：

- 不把作者如何完成工作、内部标签、验收口令、调试信息、交接说明、版本对比、TODO 或未落地方案伪装成成品内容；当前产物本身就是评审记录、调试工具或规格说明时，才按该产物的真实受众保留对应信息。
- 不为填满版面或显得完整而补造名称、指标、状态、能力、因果或产品主张。缺少承重内容时，在成品外具名报告；受众必须据此行动的不确定性，才以可辨认的未知状态进入成品。
- 可见不等于可披露。只提供该受众完成任务所需且被授权看见的细节；内部实现、敏感数据和无关系统边界不因“更完整”而出现。
- 做删除检查时，不只问它是否直接产生动作；还要问移除后，受众是否失去必要的事实、关系、判断框架、语义方向或行动能力。没有真实损失，就让它保持删除。

## 让结构与媒介承担真实关系

先找出内容之间真正承重的关系，再使用当前媒介的标题、空间、连线、分组、顺序、交互和语气表达它。层级、顺序、因果、对比、归属、状态或回路只是可能形态，不是必须依次检查的分类。不要先套卡片、章节、泳道或视觉风格，再把内容硬塞进去。

第一次接触应让受众进入正确的理解方向，但不强制所有产物都先抛结论或动作。有时答案优先，有时上下文、对比、证据或铺垫必须先建立；顺序由受众完成真实任务所需的理解路径决定。重要性不同的内容不能因为统一模板而获得相同重量，辅助说明也不能抢占承重关系。术语保持与真实对象一致；类比帮助跨越理解壁垒，不能替代准确关系。

把产物放回最终媒介校正：受众最先感知什么，按什么顺序理解，在哪里需要猜测，哪些内容被裁切、淹没或错误强调，下一步是否自然。发现结构、密度、文案或披露边界有问题，就回到真实产物继续修改。

具体 Skill 根据媒介契约和任务授权决定怎样实现、渲染与验证：代码注释回到代码上下文，界面回到真实运行表面，图形回到真实画布，文档回到最终载体。本 Skill 不自行扩大验证权限，也不把作者校正升级成完整测试或独立批准。

## 与具体 Skill 协作

调用本 Skill 的具体 Skill 继续拥有专业边界、事实来源、修改权限、媒介实现和交付格式；这里只提供跨媒介的受众、语义、内容与理解判断。两者冲突时，真实对象、用户承诺和更具体的媒介契约优先。

本 Skill 不单独创建设计说明、受众画像、检查表或长期产物。完成判断后立即回到当前具体任务，把变化落实到真实成品中；没有改变成品或具体 Skill 的决定，就没有形成独立交付。
